# 新客户开通清单（以 DemoBet88 模板为底）

约 20 分钟。每个客户 = 1 个 GitHub repo + 1 个 Railway 项目 + 1 个 Bot + 1 个子域名。

## A. 准备（客户给你的）
- [ ] 品牌名、Logo（Bot 头像用）
- [ ] 在 @BotFather 建好 Bot，拿到 BOT_TOKEN（Bot 归属你方或转交客户，事先谈好）
- [ ] 客户要发文的群/频道，已把 Bot 加为管理员（频道需给发文权限）
- [ ] 客户负责人的 Telegram ID（私聊 Bot 发 /chatid）→ 作 STORAGE_CHAT_ID / ADMIN_IDS

## B. GitHub
- [ ] 新建 private repo：`mjh-{brand}`
- [ ] 把 `demobet88-template` 内容复制进去（**不要带** .git、node_modules、data、.env），push 到 main
- [ ] 记到 `customers.txt`（同步脚本用）：`{brand} /路径/到/mjh-{brand}`

## C. Railway
- [ ] New Project → Deploy from GitHub → 选 `mjh-{brand}`
- [ ] 加 Volume，挂载路径 `/data`
- [ ] Variables：
  | 变量 | 值 |
  |---|---|
  | BOT_TOKEN | 客户 Bot 的 token |
  | ADMIN_PASSWORD | 12位以上随机（你自己保管，是恢复入口） |
  | STORAGE_CHAT_ID | 客户负责人 Telegram ID |
  | ADMIN_IDS | 同上 |
  | BRAND_NAME | 品牌名 |
  | DATA_DIR | /data |
  | PUBLIC_URL | https://{brand}-telegrambot.mjhco.com |
  | NODE_ENV | production |
  | PLATFORM_KEY | 16位以上随机（登记总汇用） |
  | **DEMO_MODE** | **不要设！** |
- [ ] Settings → Networking → Custom Domain：`{brand}-telegrambot.mjhco.com`，记下 Railway 给的 CNAME 目标

## D. Cloudflare
- [ ] DNS 加 CNAME：`{brand}-telegrambot` → Railway 给的目标，先 **灰云（DNS only）**
- [ ] Railway 显示证书 OK、网址能开后，才可改橘云

## E. 后台设定
- [ ] 用 owner + ADMIN_PASSWORD 登入 → 机器人设置：名称、简介、头像、菜单、欢迎页、常见问题
- [ ] 发布位置：添加客户的群/频道，点「测试发送」
- [ ] 员工与权限：为客户开 **超级管理员** 账号（账号名全局唯一，建议 `品牌缩写-名字`，客户从 telegrambot.mjhco.com 输入账号即可进入）（发初始密码，请客户登入后自改）；需要时再开 guest 给客户老板看

## F. 登记总汇
- [ ] 总汇 → 添加品牌：品牌名、`{brand}-telegrambot.mjhco.com`、PLATFORM_KEY
- [ ] 刷新确认显示「在线」

## G. 验收
- [ ] 私聊 Bot /start 有欢迎页；签到可用
- [ ] 后台发一则带按钮的测试贴，点击后在「数据」里看到点击
- [ ] 用户页出现你自己的账号
- [ ] 确认合同里写明：MJH 技术方可查看会员数据（PDPA 告知）
